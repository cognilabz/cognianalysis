# Flow and Mermaid Analysis Skill

Use this skill when the repository assessment needs detailed flows.

## Output focus

- Happy paths and failure paths
- Mermaid sequence diagrams, flowcharts or state diagrams
- Request/response references
- Business rule references
- Persistence, events, external calls, queues/topics and state changes
- Flow examples
- Evidence for every step

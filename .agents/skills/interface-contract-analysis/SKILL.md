# Interface Contract Analysis Skill

Use this skill when the repository assessment needs a deeper contract/interface view.

## Output focus

- REST/HTTP, GraphQL, SOAP, events, jobs, CLI commands, UI routes and external calls
- Request and response structures
- Headers, statuses, errors, faults and payloads
- OpenAPI/Swagger operations, schemas and examples
- SOAP/WSDL/XSD operations, messages, faults, SOAP actions and envelope examples
- Examples from docs/tests/contracts or inferred examples marked as inferred
- Evidence for every claim
